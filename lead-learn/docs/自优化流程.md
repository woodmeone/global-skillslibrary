# 自优化流程（跑完发现不合理 → 改 skill）

> 依据 `docs/adr/0002`：**自动改的自由度 = 测试能覆盖的范围**。
> 门禁脚本：`scripts/verify_gate.ps1`。三道闸缺一不许提交。

## 什么时候触发

不是每夜都自优化。触发条件三选一：

| 触发 | 信号 |
|---|---|
| 定时任务失败 | `run_nightly.ps1` 有 Step 返回 false |
| 盘面异常 | `health.py` 报收藏数据 > 48 小时不新鲜（选择器可能失效） |
| 人工发现 | 你看了 `dispatch.py list` 的输出，觉得判得不对 / 格式不对 |

**没有信号就不改。** 没有病的时候动刀，是这类自动化最常见的死法。

## 三步流程

### 第一步：立 Issue（G1）

在 `docs/issue-*.md` 新建或追加到已有 Issue。**必须写清**：
- 具体现象（不是「感觉不好」，是「38 份稿子里有 12 份判错」）
- 验收标准（可观测、可判定）
- 归哪张票

**不许跳过 Issue 直接改代码**——这是 `git-native-sop` 的硬约束，也是追溯链的起点。

### 第二步：改 + 验（G2）

**必须在干净上下文里改。** 不能在自己刚跑完那次会话里顺手改——
那次会话有偏好残留，会偏向「证明自己刚才判对了」。

改完跑门禁：

```powershell
cd <本 skill 所在目录>
powershell -ExecutionPolicy Bypass -File .\scripts\verify_gate.ps1
# exit 0 → 可以提交；exit 1 → 不许提交
```

三道闸：

| 闸 | 检查 | 不过怎么办 |
|---|---|---|
| 闸1 | `pytest tests/ -q` 全绿 | 补测试或修代码，**不许跳过测试提交** |
| 闸2 | `dispatch.py status` / `health.py` / `pipeline.py status` 全 exit 0 | 说明改坏了公共路径，revert |
| 闸3 | `git diff` 没碰 `SKILL.md` 的 name/description、`paths.py`、`assets/学习任务模板.md` | 撤回那部分改动 |

**闸 3 为什么禁这三个**：
- `SKILL.md` 的 `name`/`description` 改了会触发 skill 目录刷新，写错整个 skill 从会话里消失
- `paths.py` 是路径唯一出处，改错会让所有脚本找不到文件（而且报错在很晚才出现）
- `assets/学习任务模板.md` 是给子智能体的逐字提示词，改动影响面在别处

真要改这三处 → **人来做，不走自优化**。

### 第三步：提交 + 回写（G3）

```powershell
git -c core.autocrlf=false commit -q -m "fix(<区域>): <一句话>（#<Issue> 票<N>）"
```

commit message 必须引用 Issue 编号（`#N`），这是追溯链的最小单元。

## 回滚

任一闸不过：

```powershell
# 已 commit 的
git revert <sha> --no-edit

# 未 commit 的
git checkout -- <file>
```

**回滚不算失败，回滚后把原因写进 Issue 评论才算完整。** 没写原因的 revert 等于白跑一趟。

## 已知的边界（测不到的地方）

| 场景 | 为什么测不到 | 缓解 |
|---|---|---|
| B站/抖音改页面结构，选择器失效 | 测试不联网 | `health.py` 报「数据 N 小时前不新鲜」是早期信号 |
| 母版 skill（recall）接口变了 | 不在本仓库 | 闸2 的冒烟命令会崩 |
| 大模型的判断质量变差 | 判断本身没有断言 | 只能靠人看 `_ledger.md` 的丢弃理由 |

**测试覆盖不到 = 自优化不许碰 = 人来判断。** 这条边界比任何门禁都重要。

## 一条实测教训（写在这里提醒自己）

2026-11-24 我写门禁脚本时踩了两个坑，都是"看起来对、跑起来错"：

1. **函数内 `$failed += $name` 创建的是局部变量**，脚本级那个永远不变，
   于是「三道闸全过 ✓」照样打印，而闸 3 明明是红的。改成 `$script:failed`。
2. **PowerShell 5.1 在中文 Windows 上按 GBK 读 `.ps1`**，无 BOM 的 UTF-8
   文件里任何中文都会解析成乱码 → 语法错。`.ps1` 一律存 UTF-8 **with BOM**。

两条都验证过：现在改 `scripts/paths.py` 会让门禁 exit 1。
